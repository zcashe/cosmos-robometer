Robometer-Guided Best-of-N Distillation for Robust Robot Policies

CSCI 566, Fall 2026

Shift the scene by 10 cm and a near-perfect robot policy drops to 64.1% success. We let a video model pick the best of four attempts, then fine-tune the policy on those picks. The fine-tuned policy reaches 70.4% in a single attempt.

    The problem

    Cosmos Policy is a video world model fine-tuned to control a simulated robot arm. On LIBERO-Spatial it is near perfect, until things move.

    Tints, a new table and small camera moves barely matter. Moving the objects does. With the whole scene shifted 10 cm, success on our 250 held-out start states is 64.1%.

    Search with a judge, then distill

    Robometer is a video model that watches a rollout and scores its progress and success. The policy is stochastic, so we run it four times from the same start and keep the attempt Robometer scores highest. That gets 69.6%, but every episode costs four rollouts: 57.8 s against 14.5 s.

    To drop that cost we search once, on 250 training start states, keep each pick that scores at least 0.5, and fine-tune the policy on them. The student then runs once per episode.

    Result

    Trained on picks from the LIBERO-finetuned judge, the student reaches 70.4% in one attempt at 13.8 s per episode: the accuracy of best-of-4 search at a quarter of the time.

    Over four evaluation seeds it averages 71.5%, +7.4 points over the base policy (95% CI +3.1 to +11.6).

    Controls

    Three more students were trained the same way on other sets. Training on unfiltered attempts or on the base judge's picks made the policy worse than leaving it alone.

    The sets differ in size and every student got the same 2,000 updates, so we cannot yet separate set size from set quality.

    Waiting for data

    Tasks nobody trained on

    Five new cluttered tasks with lookalike distractors, 8 attempts per start state, no fine-tuning. One attempt succeeds 45.0% of the time. Best-of-8 picked by the LIBERO-finetuned judge reaches 56.0%, against a ceiling of 56.8%.

    Limits

    • Each student was trained once, and only the main student was evaluated on more than one seed.
    • The training sets differ in size (156 to 250 episodes), so set size and set quality are confounded.
    • The better judge was fine-tuned on LIBERO, the simulator we test in.
    • Best-of-N times leave out the judge's own run time.
